Meta 发布 Muse Wonder / Muse Wonder Full：14 个月后重回前沿，直逼 Claude Opus 5.5

🏷 官方披露

🕐 时间：美东时间 10月12日下午（扎克伯格当日发帖官宣；财联社北京时间 10月13日 01:01 电）

Meta 官宣两款新模型 Muse Wonder 与 Muse Wonder Full，主打「主动记忆」（跨对话延续上下文）与「主动聚焦」（长任务持续推进），均支持 100 万 token，已上线 Meta 模型 API 与编程 Agent Muse Code（Full 仅限 Muse Code 订阅）。据 Artificial Analysis 智能指数，Full 版得 56 分、仅次于 Claude Opus 5.5（58 分）、高于 OpenAI 与谷歌最强模型（均 53 分），标准版 52 分；标准版 API 定价每百万输入/输出 token 4 / 20 美元。首日 Muse Code 额度消耗异常，Meta 首席 AI 官 Alexandr Wang 承认「算错了」并将重置额度。

微软官宣 Azure Maia 300：第三代自研芯片 2027 年投产，主攻推理

🏷 官方披露

🕐 时间：美东时间 10月12日（微软官方博客发布、CNBC 当日报道；原文未注具体时刻）

微软发布第三代自研 AI 加速器 Maia 300：台积电 N2P 工艺、多芯粒设计，单颗集成 8 组 HBM4、288GB 显存与 18TB/s 带宽（约为 Maia 200 的 2.5 倍）；每机架可装 96 颗、功耗 167kW，机架级 token 吞吐最高为 Maia 200 的 7 倍，微软称每兆瓦有效算力较「领先的 GPU 系统」高约 40%（未点名对比对象）。Maia 300 将于 2027 年起生产部署、扩展至多吉瓦规模，并将成为微软自有产品与 API 服务背后的主要推理系统。

Anthropic 红队研究：小模型「或已临近」在智能家电上自我复制

🏷 官方披露

🕐 时间：美东时间 10月12日（Anthropic 研究博客发布日；原文未注具体时刻）

Anthropic Frontier 红队发文称，小型 AI 模型可能「数月内」就具备在商用 IoT 设备（如智能烤箱、杂牌 Android 电视盒子）上自我复制的能力，且因没有中心节点而难以关停。实验显示：9B 模型已在 9 类硬件中的 8 类跑通推理；团队用 15 台约 55 美元的电视盒分布式运行 26B 模型（0.39 tokens/秒）；唯一完成端到端复制的是开源模型 GLM-5.2（5 次试验有 4 次扩散至全部 8 个节点）。研究强调测试中攻击步骤被刻意简化，结果为现实成功率的「上界」。

出处 Anthropic · AI models may be capable of self-replicating without access to a datacenter · Unite.AI · Anthropic Red Team Says Small AI Models May Soon Replicate on IoT Devices

智谱发布并灰度 GLM-Legal：瞄准真实律所工作流

🏷 官方披露

🕐 时间：10月12日（Z.ai 官方博客标注日期；原文未注具体时刻）

智谱（Z.ai）发布法律领域模型 GLM-Legal，基于 GLM-5.3-Flash 构建，覆盖合同审查、证据分析、合规等场景。官方称其在 Harvey LAB 覆盖 24 个法律业务领域的真实律所工作流评测中，端到端任务全部通过率达 19.2%、较基座模型提升 12.5 个百分点并超越 Claude Fable 5，在 LegalBench、PLawBench 上比肩前沿闭源模型。目前以设计合作方式开放 API 申请，后续将进入 AutoClaw 桌面端。

Linus Torvalds 用 Claude Code 写内核补丁：小读吞吐近 3 倍

🏷 媒体解读

🕐 时间：美东时间 10月12日（Phoronix 报道；补丁分支经 Linux 邮件列表披露；原文未注具体时刻）

Linus Torvalds 推送实验分支 noref-filemap-read-with-llm，重写页缓存小读路径以消除 folio 引用计数争用（改用 RCU）；其笔记本 8 线程基准下，小读吞吐从约 1000 万次/秒提升至 3300 万次/秒，单次读内核周期从约 2950 降至 725。他在补丁信中明确：代码、测试程序、问题清单评审与信初稿均由 Claude Code 在其指导下完成，测量由本人执行。分支基于 7.3-rc6，尚未合并。
