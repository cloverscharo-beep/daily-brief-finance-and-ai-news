月之暗面发布 Kimi Code Desktop：编程智能体迎来官方桌面客户端

🏷 官方披露

🕐 时间:9月21日（北京时间，月之暗面当日宣布；原文未注具体时刻）

Kimi Code Desktop 正式上线，macOS 与 Windows 版同步推出，可从 kimi.com/code 安装。作为 Kimi Code 的官方桌面客户端，用户可在桌面端直接调用其 AI Agent 读写代码、运行命令、完成自动化任务，并通过图形界面集中管理项目、查看 Agent 每一步执行；还内置终端、浏览器与 Git 状态视图，可审阅改动、关联 PR 状态。官方称本地 CLI 任务会直接出现在桌面端，1.0 只是开始。

Google 开源智能体编排器 AX：声明式任务、亚秒级挂起恢复，登顶 Hacker News

🏷 官方披露

🕐 时间:9月21日（北京时间，当日登顶 Hacker News；仓库属 Google 官方 GitHub 组织，原文未注具体时刻）

Google 开源的智能体编排运行时 AX（Agent Executor）当日冲上 Hacker News 榜首。它把 Agent 视为轻量 Actor，在 Kubernetes 与 Agent Substrate 之上提供四个原语——Task（隔离执行）、Workspace（仓库／MCP／技能）、Gateway（网络与凭据）、Model（模型参数集中配置）；宣称单集群可承载数十亿并发会话、空闲任务亚秒级挂起恢复、密集复用降低闲置成本，还支持「生成式工作区」：用自然语言描述环境，Agent 自行安装工具链。项目以 Apache 2.0 开源，被形容为「不替代 LangGraph/CrewAI，而是运行在它们之下」。

出处 AX 官方网站 · explainx.ai · Google AX Explained: Open Agentic Orchestrator

OpenAI 官方通告：9月24日 移除 Videos API 与全部 Sora 2 模型，无替代方案

🏷 官方披露

🕐 时间:9月21日（北京时间，多家媒体与开发者社区当日刊发迁移提醒；OpenAI 于 3月24日 发出弃用通知，下线生效日为 9月24日）

「Pirate Face」把开源模型做成磁力链接：Hugging Face 删档后由 P2P 蜂群续命

🏷 博主解读

🕐 时间:9月21日（北京时间，Hacker News 当日热门条目；站点于 9月20日 增补 tracker 与 DHT 发现层，原文未注具体时刻）

新上线的 Pirate Face 将 Hugging Face 上宽松许可的模型打包为带 web-seed 的 BitTorrent 磁力链接：每个权重文件校验官方 SHA-256，HF 在线时直连下载、删档后自动回落到 P2P 蜂群，并把这类模型标记为「Rescued」；设置 HF_ENDPOINT 即可让现有流水线无缝切换。站点自称目录覆盖 66.9 万余个「可镜像」仓库，页面亦提示目前仍依赖 HF 与社区。有分析提醒：目录数只是「资格数」，并不等于当年被真正确保留存的模型量。
