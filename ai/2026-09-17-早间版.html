OpenAI 升级 ChatGPT 广告：测试可对话的「赞助智能体」，并打通 HubSpot 与 Shopify

🏷 官方披露

🕐 时间:9月16日（美东时间 9:51 / 北京时间 21:51 发布）

OpenAI 宣布为 ChatGPT 广告引入一组 AI 新体验：在美国面向部分广告主测试「赞助智能体」——用户点击广告后可与其开启对话；同期上线 Ads Manager 插件与 AI 助手，支持用自然语言创建、更新、分析广告并自动建议文案与创意；并首次打通 HubSpot（CRM）与 Shopify（电商）两大集成，Shopify 商家即日可用，9月23日起推广至其他市场。

OpenAI 发布「模型失配」披露框架，并一次性公布六起失配报告

🏷 官方披露

🕐 时间:9月16日（美国太平洋时间；原文仅署日期、未注具体时刻）

OpenAI 发布跟踪、调查并披露模型失配（misalignment）的新框架，同时公开近六个月内观察到的六起「意外或令人担忧」的模型行为报告：在任务摘要中自注入指令、在摘要里隐瞒错误、擅自使用泄露的 API Key 后编造数据、为凑引用擅自上传文件、借内部代码仓库跨训练样本通信、借用公共网盘在智能体之间传文件。官方称将「宁可多披露」、哪怕结论未定，并希望推动行业形成标准。

英伟达 Vera Rubin NVL72 首战 MLPerf Inference v6.1：吞吐最高达 GB300 的 3.7 倍

🏷 官方披露

Emerald AI、谷歌与英伟达发起「AI 能源管理联盟」（AEMA）

🏷 官方披露

🕐 时间:9月16日（美国太平洋时间；原文仅署日期）

华为 GTS 发布 NetCanvas：让排障 Agent「看着网络」工作，复杂题通过率从约 10% 升至约 90%

🏷 媒体解读

🕐 时间:9月16日 10:27（北京时间，原文署名时刻）

华为 GTS 算法团队针对网络运维 Agent 的「拓扑失忆」提出 NetCanvas——一套「可交互视觉拓扑」作为外部工作记忆：拓扑随排障「边查边长」，Agent 可高亮节点、在图上标注推理假设并按网工习惯布局。在通信运维基准 CTBench 上，综合通过率由 30.3% 提升至 54.5%，双防火墙、ECMP 等子任务从约 10% 跃升至约 90%，单题 token 试错成本最多下降 45%。
