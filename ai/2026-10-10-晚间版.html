腾讯云开源 TeamAI：团队 Skill 走 Git 评审分发，适配 16 种 Agent

🏷 官方披露

🕐 时间：10月10日 15:56（北京时间；观点网发稿时刻；腾讯云当日宣布开源，未注具体时刻）

腾讯云宣布开源内部自用工具 TeamAI（GitHub：Tencent/teamai-cli）：基于 Git 把团队 Skill、工作规范、工具配置与项目知识统一入库，像管理代码一样评审、更新与版本管理，再同步到成员各自的 Agent，实现「一人配置、全员复用」，目前已适配 WorkBuddy、Claude Code、Codex、Cursor 等 16 种 Agent。官方内测显示：接入团队知识的较低成本模型，综合评分比未接入的更高规格模型提高 6.1%，模型调用成本降低 76%；该项目已登上 GitHub Trending。

MIT 等研究：固定回答开头的两个 Token，基座模型数学推理可追平强化学习版

🏷 媒体解读

🕐 时间：10月10日（北京时间；智东西当日报道，原文未注具体时刻）

智东西报道一项来自 MIT 等机构的研究：不改模型参数、不加新示例，只要把回答开头固定为两个特定 Token，数学推理成绩即可接近其强化学习（RL）版本。以 Olmo-3-7B 为例，将开头固定为「.\n\nOkay」后，MATH-500 准确率从 42% 升至 78%，超过其 RL 版的约 75%；Qwen3-14B 的有效开头为「 Alright,」。研究认为，RL 的一部分作用可能正是让模型更容易选择有效的回答开头。

出处 智东西 · 00 后硕士揭开 AI 推理「黑科技」：两个 Token，基模追平强化学习版本 · 新浪新闻转载
